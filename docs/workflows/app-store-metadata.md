## プロモーションテキスト (170字)
「いつかやりたい」、保存したまま忘れていませんか？Wishes は、他のアプリの共有ボタンからワンタップで保存。あとはAIが自動で整理して、ちょうどいい時期にそっとお知らせ。集めた「いつか」を、ちゃんと「やった」に変えていくアプリです。

## 説明文 (4000字)
気になったこと、やりたいこと。SNSやWebサイトで見つけて「いつかやろう」と思ったことを、そのまま放置していませんか？

Wishes は、その「いつか」を、ちゃんと「やった」に変えるためのアプリです。ただ管理するだけでなく、“叶える”ところまで、そっと手伝います。

なんとなく過ごしてしまっていた日々を、少しずつアップデートしませんか？

■ 他のアプリからでも、ワンタップで保存。
Safari やマップ、SNS で気になったお店・場所・記事は、共有ボタンから Wishes へ。アプリを切り替えず、思いついた瞬間にそのまま追加できます。

■ 面倒な入力は、AIにおまかせ。
URL を渡すだけで、AI がタイトル・シーズン・タグまで自動で下書き。ぽちぽち手入力する手間は、もういりません。（AIの処理はすべて端末内で動作します）

■ ゆるく整理。タグ地獄にはしない。
優先度（高・中・低）／シーズン（春夏秋冬・月・いつでも）／タグ（飲食・旅行・レジャー・お買い物＋自由に追加）の3軸で、ざっくり分類。仕事のタスク管理みたいに、しんどくなりません。

■ ちょうどいいタイミングで、そっと提案。
金曜は今週末、月初は今月、季節の前にはその季節——。今のあなたに合う「いつか」を、最大3つだけ、そっと差し出します。

■ 叶えた数が、増えていく。
チェックを付けると達成として記録。今年いくつ叶えたかがひと目でわかり、あなたの希望ペースに合わせて、次の一歩をそっと後押しします。

■ プライバシーは最優先。
リストの内容はすべて端末内に保存。アカウント登録は不要で、広告やトラッキングはありません。アプリ改善のために匿名の利用統計だけをお預かりしますが、書いた内容が送られることはなく、設定からいつでもオフにできます。

> v1.1 以前の文言は「広告・トラッキング・分析は一切ありません」。v1.2（アナリティクス導入）で上記に差し替え（[ADR 0006](../decisions/0006-利用状況アナリティクス.md)）。ASC の説明文は自動複製されるので、次回提出時に手で更新すること。

## アプリ内課金（IAP）
> ⚠️ **v1.0 では課金機能を無効化して無料リリース**（`FeatureFlags.proEnabled = false`）。URL自動取り込みは全員無制限。以下は**将来 Pro を有効化する際の参照用**で、v1.0 提出時は ASC での IAP 作成・Paid Apps 契約は不要。

| 項目 | 値 |
|---|---|
| 参照名 | BucketList Pro |
| Product ID | `teratech.BucketList.pro` |
| タイプ | 非消費型（Non-Consumable） |
| 価格 | ¥600（該当の価格帯を選択） |
| 表示名 (ja) | Wishes Pro |
| 説明 (ja) | URLからやりたいことを無制限に自動取り込み。対応端末では端末内AIがタイトル・優先度・季節・タグまで自動で下書きします。 |
| レビュー用スクショ | Paywall画面のスクショ1枚（必須） |

補足（**将来モデル**）: Pro 有効化後は、URLからの自動取り込みは無料で10回まで（`Storage.freeCaptureLimit = 10`）、それ以降は手入力で保存可。Pro（買い切り）で自動取り込みが無制限になる。基本機能は無料で全て利用可。
※ **v1.0（現行）ではこの上限は無効**（`FeatureFlags.proEnabled = false` のため `canAutoCapture` は常に true）。全員が自動取り込みを無制限に使える。

## App Review に関する情報（審査メモ）
審査担当者向けに以下を記入（英語推奨だが日本語審査なら日本語可）:

- 本アプリはアカウント不要・ログイン不要です（デモ用アカウントは必要ありません）。
- ユーザーのリスト内容はすべて端末内（App Group）に保存し、外部サーバーへ送信しません。アプリ改善のため匿名の利用状況イベント（Firebase Analytics）のみ送信し、設定画面でオフにできます。
- 「AI」機能は Apple のオンデバイス基盤モデル（対応端末）またはルールベースで動作し、外部APIを呼びません。共有・貼り付けられたリンクは、タイトル/タグの下書きのために端末上でそのリンク先のみ取得します。
- 本バージョンは課金機能なしの無料アプリです（アプリ内課金は提供していません）。URL自動取り込みを含む全機能を無料で利用できます。
- 動作確認手順: ホームの「＋」から追加シートを開き、タイトルを入力して保存 →リストに追加されます。URL欄にリンクを貼ると端末内で下書きが生成されます。共有シート（Safari等の共有→Wishes）からも追加できます。
